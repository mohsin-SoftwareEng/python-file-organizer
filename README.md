# Python File Organizer

A beginner-friendly Python project that automatically organizes files into folders based on their file extensions.

## Features

* Organizes Images, Videos, and Documents
* Automatically creates folders if they do not exist
* Uses Python built-in modules:

  * os
  * shutil

## Supported File Types

* .png
* .jpeg
* .pdf
* .mp4
* .mkv
* .pptx

## How It Works

The program scans a selected directory and moves files into separate folders according to their extensions.

Example:

* Images → Images folder
* Videos → Videos folder
* Documents → Documents folder
